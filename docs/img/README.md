# Screenshots

The root README explains every setup step in words, so it works without pictures. This is
the checklist of screenshots to add later. When one is ready, put a normal Markdown image
right after the step it shows (the "README spot" column), and add a "Last checked" date
next to setup shots, because claude.ai menus change.

Take every screenshot with a fictional account and fictional resume (use the sample in
`examples/sample-run/`). No real names, emails or phone numbers.
